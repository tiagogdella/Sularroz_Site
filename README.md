📄 README – Sularroz_Site
🇧🇷 Português
🟢 Visão Geral

Sularroz_Site é o site institucional da marca Sularroz, desenvolvido como primeiro projeto real para uma empresa em produção. O site está em uso atualmente e tem como objetivo apresentar a empresa, seus valores e seus produtos ao público de forma clara, acessível e visualmente agradável.

🛠 Tecnologias

Este projeto foi desenvolvido com as seguintes tecnologias:

HTML

CSS

🌾 Sobre a Sularroz

A Sularroz é uma empresa do setor de arroz beneficiado que valoriza a tradição e a qualidade em cada grão do campo à mesa. Ela atua no beneficiamento de arroz com foco em atender famílias e clientes com um produto confiável e saboroso.

🎯 Objetivo do Projeto

O site foi construído para:

Apresentar a marca Sularroz de forma profissional;

Divulgar informações institucionais da empresa;

Tornar acessível ao usuário a proposta, os valores e os diferenciais da marca;

Oferecer uma presença digital clara e funcional.

📈 Em produção

Este projeto não é apenas um protótipo: ele está em uso real pela empresa, servindo como página oficial de apresentação da Sularroz.

🟢 Overview

Sularroz_Site is the official institutional website for the Sularroz brand, created as a real-world project for a company and currently live in production. The site’s purpose is to showcase the company, its values, and its products in a clean, user-friendly, and professional way.

🛠 Technologies

This project was built using:

HTML

CSS

🌾 About Sularroz

Sularroz is a rice processing company that values tradition and quality from the field to the table. The brand focuses on delivering a trustworthy and delicious rice product for families and clients alike.

🎯 Project Goals

The website was developed to:

Professionally present the Sularroz brand;

Publicly share the company’s mission and institutional information;

Provide a clear and functional digital presence for users and potential customers.

📈 In Production

This is not a mockup: the site is actively live and in use by the company, serving as its official digital presence.
